# inspo/

Drop resume PDFs you admire here — resumes with a register, density, or formatting you want
your bullets to match. The skill can read them to calibrate voice and phrasing.

**These files are gitignored** (`inspo/*.pdf`), so nothing you put here is ever committed or
published. That's deliberate: reference resumes usually belong to other people, and their
contents (and identities) should stay private to your local copy.

This README is the only tracked file in the folder — it's just here so the folder exists on a
fresh clone.
