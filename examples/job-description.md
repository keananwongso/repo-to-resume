We're hiring software engineering interns to build and ship backend services and data
tooling used across the company. You'll own features end to end: design, implementation,
testing, and deployment.

## Minimum qualifications
- Currently pursuing a BS/MS in Computer Science or a related field.
- Proficiency in one or more of: Python, Java, C++, JavaScript/TypeScript.
- Understanding of data structures, algorithms, and software design.
- Experience with REST APIs and relational databases (e.g. PostgreSQL).

## Preferred qualifications
- Experience building and deploying services with Docker and CI/CD pipelines.
- Familiarity with caching (Redis), message queues, or distributed systems.
- Comfort with testing frameworks and writing maintainable, well-tested code.
- Exposure to cloud platforms (AWS, GCP) and infrastructure-as-code.
- Front-end experience with React is a plus.

## Responsibilities
- Design and build scalable backend APIs and services.
- Improve reliability, latency, and throughput of existing systems.
- Write tests and participate in code review.
- Collaborate across teams to ship customer-facing features.
